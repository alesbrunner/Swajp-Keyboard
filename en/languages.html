Language packs

Languages that are not built into the app can be added as a pack. It is a plain zip with a dictionary – nothing gets installed and the app needs no internet for it.

Download all languages (14 MB)

How to add a pack

  1. Download a zip – one language or all of them. It is saved to your Downloads folder.
  2. Open Swajp → Settings → Languages → More languages (packs).
  3. Tap Import language pack (zip) and choose the downloaded file.
  4. Select the new language as your main or second language.
